# Мета
Метою роботи є оволодіння механізмами ітерації в Python (ітератори, генератори), розробка потокових конвеєрів для обробки великих наборів даних та порівняння переваг `lazy` та `eager` підходів.

## Опис алгоритму (Варіант №3)
Для виконання роботи було обрано варіант №3 (Потокова обробка даних інтернет-магазину).

1. **Джерело даних**: Файл `data/products.csv` обсягом 100 000 записів.
2. **Streaming reader**: Використання генератора, що зчитує файл построково через `yield from`.
3. **Парсинг та Валідація**: Генератор `validate_products` перетворює рядки CSV у `NamedTuple`, ігноруючи записи з некоректними типами даних.
4. **Фільтрація та Трансформація**: Застосування генераторних виразів для фільтрації товарів за категорією.
5. **Batch Processing**: Реалізовано функцію `batched` через `itertools.islice`, що дозволяє обробляти дані порціями для економії пам'яті.
6. **Аналітичні функції**: Обчислення агрегатних показників (сумарна вартість залишків, найдорожчий товар) проводиться в один прохід через ітератор, без завантаження всього списку в оперативну пам'ять.
7. **Порівняння**: Реалізовано `eager` версію (завантаження всього `list` у пам'ять) та `lazy` версію (генератор), які порівнюються за піковим використанням RAM через модуль `tracemalloc`.

## Висновок
У ході лабораторної роботи було успішно побудовано потоковий конвеєр обробки даних інтернет-магазину. Використання протоколу ітераторів та генераторів (`yield`, `yield from`, `generator expressions`) дозволило обробляти набір з 100 000 записів з мінімальним споживанням оперативної пам'яті. 
Основні висновки:
- `Lazy evaluation` значно знижує пікове використання пам'яті порівняно з `eager` підходом.
- Генератори є незамінними при роботі з потоками даних, де розмір набору невідомий або перевищує можливості ОЗП.
- `itertools` значно спрощує реалізацію складних операцій, таких як пакетування, групування та накопичення результатів.
