# Лабораторна робота №3
## Тема: Ітератори, генератори та потокова обробка даних

## Мета роботи
Опанувати ітераційну модель Python, навчитися створювати власні генератори, використовувати протокол ітераторів та будувати ліниві (lazy) конвеєри для обробки потоків даних без повного завантаження в оперативну пам'ять.

## Опис алгоритму та архітектури (Варіант №3)
Для виконання завдання варіанта №3 було побудовано пайплайн, що складається з чотирьох основних етапів:
1. **Джерело (Producer):** Генератор `generate_mock_data`, що імітує потокове надходження даних.
2. **Парсинг:** Функція `stream_reader`, яка перетворює "сирі" рядки на структуру даних (словник).
3. **Фільтрація:** `filter_success` відсіює невдалі транзакції за допомогою генераторного виразу.
4. **Трансформація:** `apply_tax` виконує бізнес-логіку обчислення податку.
5. **Агрегація:** Використано `itertools.groupby` для підрахунку суми по групах.

## Опис реалізованих функцій та класів
- `generate_mock_data(n)`: Генераторна функція, що створює тестовий потік даних (замість читання з файлу).
- `stream_reader(source)`: Функція, що обробляє потік рядків та повертає ітератор словників.
- `filter_success(data)`: Фільтратор, що використовує `yield from` для передачі лише успішних транзакцій.
- `apply_tax(data)`: Генератор, що змінює значення `amount` залежно від умови, демонструючи lazy transformation.

## Результати виконання програми
Програма успішно обробляє потік даних, застосовуючи фільтрацію та податкові нарахування. Завдяки використанню ітераторів, на кожному етапі в пам'яті знаходиться лише один елемент (або поточна група), а не весь масив даних.

## Висновки
У ході роботи було доведено ефективність lazy evaluation. Використання генераторів дозволяє будувати конвеєри, які споживають мінімальну кількість пам'яті навіть при обробці великих наборів даних. Завдяки модулю `itertools` (зокрема `groupby`), складні операції групування стають лаконічними та продуктивними. Встановлено, що ключем до потокової обробки є уникнення операцій, які потребують повного зрізу (матеріалізації) даних.
