# Мета роботи
Ознайомлення з ітераційною моделлю Python, розробка потокових (lazy) конвеєрів для обробки даних, мінімізація споживання пам'яті при роботі з великими наборами об'єктів.

## Опис алгоритмів та архітектури (Варіант №3)
Архітектура побудована на принципі "Lazy Evaluation". Замість матеріалізації всього списку товарів у пам'яті (Eager Evaluation), ми використовуємо:
1. **Генератори (`read_products_lazy`)**: дозволяють читати файли по одному рядку.
2. **Generator Expressions**: забезпечують відкладену фільтрацію (`filter_by_category_lazy`).
3. **`itertools.islice`**: для реалізації механізму batching, що дозволяє обробляти великі дані порціями без ризику переповнення ОЗП.
4. **Потоковий конвеєр**: об'єднання цих елементів у ланцюжок, де кожен наступний елемент отримує дані лише тоді, коли він викликає `next()`.

## Хід тестування та результати
Тестування проведено на симульованому потоці даних із 20 об'єктів `Product`.
- Створено конвеєр: джерело -> фільтрація за категорією 'Electronics' -> застосування знижки 10% -> групування по 3 елементи.
- Результат показав правильність роботи генераторів: кожен етап конвеєра виконувався лише в момент ітерації циклу `for`.
- Споживання пам'яті залишається сталим незалежно від кількості об'єктів, оскільки в пам'яті зберігається лише поточний оброблюваний батч.

## Висновки
Під час виконання лабораторної роботи було опановано роботу з ітераторами та генераторами. Реалізація lazy pipeline дозволяє ефективно обробляти великі обсяги даних, що є критично важливим для продуктивності інтернет-магазину. Використання `yield` замість повернення списків значно зменшує навантаження на систему при виконанні складних фільтрацій та трансформацій.
