# Лабораторна робота №3
## Тема: Ітератори, генератори та потокова обробка даних
## Мета роботи
Сформувати практичні навички роботи з ітераційною моделлю Python, ітераторами, генераторами, yield, generator expressions, модулем itertools та принципом lazy evaluation при побудові потокових конвеєрів обробки даних.

## Опис алгоритму та архітектури (Варіант №3)
Варіант №3 передбачає обробку потоку даних (транзакцій). Архітектура реалізована як "Lazy Pipeline":
1. **Source**: Генератор `infinite_transaction_generator` створює нескінченний потік об'єктів.
2. **Intermediate stages**:
   - `filter_successful`: Відсікає невдалі транзакції.
   - `apply_cashback`: Змінює стан об'єкта (додає 10% до суми) за допомогою `yield`.
   - `filter_high_value`: Відфільтровує транзакції за пороговим значенням.
3. **Termination**: `itertools.islice` обмежує нескінченний потік 5 елементами для виведення.

## Опис реалізованих функцій та класів
- `Transaction`: Клас для представлення структури даних транзакції.
- `infinite_transaction_generator()`: Генератор, що імітує постійний потік даних.
- `filter_successful()`: Використовує generator expression для ледачої фільтрації.
- `apply_cashback()`: Функція-генератор, що демонструє покрокову зміну даних.
- `filter_high_value()`: Використовує вбудовану функцію `filter` для lazy evaluation.

## Результати виконання програми
Програма успішно ініціалізує конвеєр, обробляє нескінченний потік, не завантажуючи його в пам'ять повністю, і видає перші 5 транзакцій, що відповідають критеріям (статус "success" та сума > 500 після кешбеку).

## Висновки
У ході лабораторної роботи було освоєно механізми `iter`, `next`, `yield`. Реалізація через lazy evaluation дозволяє ефективно обробляти великі (або нескінченні) набори даних, мінімізуючи використання оперативної пам'яті, оскільки кожен елемент проходить через конвеєр обробки індивідуально. Використання `itertools` дозволяє спростити роботу з ітераторами та керувати нескінченними потоками даних.
