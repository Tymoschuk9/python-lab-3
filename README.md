# Лабораторна робота №3
## Тема: Обробка помилок, файли та серіалізація
## Мета роботи
Сформувати практичні навички створення надійних Python-програм, які коректно працюють із помилками, файловими ресурсами, конфігурацією та структурованими форматами даних.
## Опис алгоритму та архітектури (Варіант №3)
Архітектура побудована на принципі стрімінгової обробки даних (streaming I/O). Головний клас `DataProcessor` ініціалізується конфігурацією. Процес включає валідацію кожного рядка окремо, що дозволяє пропускати некоректні дані без зупинки всього процесу. Атомарність запису реалізована через `NamedTemporaryFile` та `os.replace`.
## Опис реалізованих функцій та класів
- `DataProcessor`: основний клас для керування пайплайном.
- `atomic_write`: контекстний менеджер для безпечного запису файлів (гарантує, що пошкоджений файл не замінить оригінал).
- `stream_csv`: генератор, що зчитує файл по рядках, не завантажуючи весь вміст у пам'ять.
- `validate_record`: функція перевірки даних з механізмом викидання custom exceptions.
## Результати виконання програми
Програма успішно обробляє коректні дані, логує помилки валідації (рядок з "error" в ID) у файл `process.log` та створює структурований JSON-файл за умови успішної валідації всіх коректних записів.
## Висновки
Опановано механізми обробки виключень, роботу з контекстними менеджерами та створення надійних інструментів для імпорту/експорту даних. Застосування `exception chaining` та власної ієрархії виключень дозволило зробити код більш стійким до помилок та зручним для налагодження.
